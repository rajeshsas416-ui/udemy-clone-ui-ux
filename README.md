# 🎓 Udemy Platform UI/UX & E-Learning Web Application

A full-featured, responsive, and modern Udemy clone web application built with clean architecture, interactive video player, real-time course search, student progress tracking, and shopping cart.

![Udemy UI Clone](https://images.unsplash.com/photo-1516321318423-f06f85e504b3?auto=format&fit=crop&q=80&w=1200)

---

## 🌟 Key Features

* **Authentic Udemy Branding & UI**:
  * Accurate color palette (`#a435f0`, `#1c1d1f`, `#b4690e`), responsive grid, and typography.
  * Categories dropdown, flash sale hero banners, and enterprise trust logos.
* **Course Catalog & Live Filter**:
  * Pre-loaded with realistic courses across **Web Development**, **Machine Learning / AI**, **AWS Cloud**, **Figma UI/UX**, and **Cybersecurity**.
  * Instant search and domain filter tabs.
* **Course Landing & Detail View**:
  * Expandable curriculum accordion with lecture duration and preview toggles.
  * "What you'll learn" checklist, instructor profiles, and student review ratings.
  * Sticky purchase sidebar with discount timer and 30-day money-back guarantee.
* **Interactive Video Learning Dashboard (Player)**:
  * Full HD video player with custom playback controls.
  * Lecture playlist sidebar with checkable completion tracking.
  * Dynamic progress bar calculation (e.g. `25% complete`).
  * Claimable Certificate of Completion.
* **Shopping Cart & Checkout**:
  * Cart state management, item removal, and instant checkout / enrollment simulation.
* **Student Dashboard ("My Learning")**:
  * Centralized view of all enrolled courses with progress bars and "Continue" shortcuts.
* **Instructor Studio**:
  * Modal to create and publish new courses into the active catalog on the fly.

## 🚀 Getting Started

### Option 1: Direct File Launch (Zero Dependencies)
Simply open `index.html` or `udemy_platform.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run with Local Node.js Server
```bash
node server.js
```
Then visit: `http://localhost:3000`

### Option 3: Full React / Vite Application
If you want to run the React + Tailwind modular application:
```bash
cd udemy-app
npm install
npm run dev
```
